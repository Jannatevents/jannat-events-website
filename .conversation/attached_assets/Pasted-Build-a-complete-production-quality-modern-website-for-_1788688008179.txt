Build a complete, production-quality modern website for **Jannat Events**, a South Asian/Bollywood entertainment and nightlife company operating across Canada.

Reference the existing business website:
https://jannat.events/

Reference Instagram:
https://www.instagram.com/jannatcanada/

Use the existing website and public information as a reference for the business, but DO NOT simply copy the old website's design. Create a completely new, premium, modern visual identity and user experience.

IMPORTANT:
This website must be designed as a REAL WORKING WEBSITE, not a static mockup.

The most important requirement is that the Jannat team should be able to update events, photos and videos regularly without needing to edit source code.

==================================================
BRAND DIRECTION
===============

Jannat Events is a premium South Asian entertainment/event brand.

The design should feel:

* Premium
* Modern
* Energetic
* Bollywood-inspired
* Nightlife-focused
* Sophisticated
* Youthful
* Canadian
* Cinematic
* Social-media friendly

Avoid generic corporate website design.

Avoid making the website look like an AI-generated template.

Use strong typography, beautiful imagery, subtle gradients, glass effects where appropriate, cinematic transitions and high-quality spacing.

The website should feel closer to a premium nightlife/event production company than a traditional event website.

Use dark luxury aesthetics as the primary direction, with carefully chosen accent colors inspired by Bollywood/nightlife.

Do NOT overuse gradients, glowing effects or animations.

Animations should feel intentional and premium.
